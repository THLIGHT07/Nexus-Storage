Mic needs localhost or HTTPS
Browser blocks microphone on file:// — you need a local server. Takes 1 minute:
1
Make sure Python is installed
Download free from python.org/downloads if you don't have it
2
Go to your website folder
Open the folder where index.html is saved
3
Windows: Double-click start-server.bat
Mac / Linux: Double-click start-server.sh or run:
python3 -m http.server 8080 in terminal
4
Open in browser: http://localhost:8080
Mic will work perfectly there ✅
